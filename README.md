# EasyControl 简易版本控制

轻量、傻瓜化的可视化 Git 版本管理小工具。不懂命令行也能用：
给每次提交起个好记的别名，鼠标点一下就能把任意历史版本覆盖回本地。

## 功能

- **查看历史**：打开任意 Git 项目，表格列出所有分支的最近 200 条提交
- **起别名**：给 commit 起易记的名字，如“稳定版”“第一次上线”“给客户演示版”
- **一键回退**：鼠标选中历史版本，点“恢复此版本到本地”，确认后本地文件即变为该版本
- **安全提示**：每次恢复前都弹窗确认；工作区有未提交改动时会醒目提醒
- **绿色便捷**：别名存在仓库 `.git\ec_aliases.json` 里，不污染 git 历史、不会被提交

## 使用步骤

1. 双击 `EasyControl.exe`（或用 `python ec_control.py` 运行）
2. 点击右上角“选择仓库...”，选中你的项目文件夹（必须是 git 仓库）
3. 在列表里点选一个版本：
   - **设置别名**：输入好记的名字
   - **清除别名**：删除该版本的名字
   - **恢复此版本到本地**：确认后把本地文件覆盖成该版本的样子
4. 顶部“刷新”按钮重新读取最新提交；“打开仓库文件夹”可直达项目目录

## 界面说明

| 列 | 含义 |
| --- | --- |
| 别名 | 你给该版本起的名字（绿色显示） |
| commit | 提交的短 hash（蓝色 = 当前 HEAD） |
| 提交时间 | 提交日期时间 |
| 提交信息 | commit message |
| 作者 | 提交人 |

底部状态栏实时显示：当前分支、是否有未提交改动。

## 安全说明

- “恢复版本”只覆盖**本地文件**，不修改分支指针、不会自动提交
- 恢复前必弹确认框；若工作区有未提交改动，会列出改动文件并加警告
- 未提交的改动被覆盖后**无法自动找回**，操作前请看清提示
- 想要更稳的做法：先对当前状态 `git commit` 或 `git stash` 后再恢复

## 打包成独立 exe

双击运行 `build_exe.bat`，自动安装 PyInstaller 并生成 `dist\EasyControl.exe`。
生成的 exe 免 Python 环境，双击即用，可拷给同事使用。

## 环境要求

- Windows（GUI 用系统自带 Tkinter）
- Git 已安装并加入 PATH（`git --version` 可查到）
- 开发/源码运行：Python 3.8+（无需额外依赖）
